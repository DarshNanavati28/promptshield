# Security policy

PromptShield is a demonstration project, not a production security boundary. Do not send real credentials or confidential user content to the demo.

## Reporting an issue

Please report suspected vulnerabilities privately to the repository owner before posting details publicly. Include the affected file, reproduction steps, expected behavior, and any relevant policy configuration. Avoid including real secrets or personal data.

## Scope

The demo has no server-side model integration or persistent event store. The screening rules are intentionally inspectable and can miss unseen attacks. A successful fixture score must not be treated as proof that a deployment is secure.
